# App UI：黑色品牌基调 · 简约（Black-forward Brand）

「**品牌色为黑色**」指：**视觉识别以中性深色与黑白对比为主**，而不是铺满纯黑 `#000` 或只用一种灰。界面结构靠**层级灰、细线边框与极少彩色点缀**完成；交互状态仍需**可识别的强调色**（本项目为 **`--accent`**，与「黑品牌」并行：黑负责气质，accent 负责「可点的」）。

## 品牌色（黑色风格）怎么用

| 维度 | 做法 |
|------|------|
| **主识别** | Logo、主标题、关键分割线、外框/导航条：用 **深灰黑叠层**（如 `--bg`、`--text-h` 一段），避免整屏死黑。 |
| **正文** | 用 **中灰**（`--text`）与标题（`--text-h`）拉开对比，保证可读，而不是把正文也做成浅灰贴黑底。 |
| **界面结构** | 用 **`--border` 发丝线**、**`--code-bg` / `--social-bg` 弱一级底** 区分区块；少用阴影堆叠（暗色下 `--shadow` 宜弱或 `none`）。 |
| **主操作 / 链接** | 仍需 **单一强调色**（`--accent`、`--accent-bg`、`--accent-border`），否则用户找不到焦点；黑色是品牌气质，不是取消交互反馈。 |
| **错误 / 成功** | 使用语义色令牌（如 **`--error-*`**），不要强行改成黑白，以免损害可访问性。 |

## 气质（与「简约科技」一致）

- **深而不闷**：背景偏冷灰黑（如 `#16171d`），卡片/代码区略抬一层（`--code-bg`）。
- **线面结合**：分隔与控件轮廓优先 **`--border`**；层次来自 **底色差**，而非多层投影。
- **可读优先**：禁止「浅灰字叠深灰底」过低对比；不要用 `opacity` 叠出第三条灰代替 **`--text`**。

## 令牌（实现）

全局只在 **`app-client/src/index.css`** 维护变量；暗色与 **`html.theme-dark`** 使用同一套深色令牌（见文件中 **`prefers-color-scheme: dark`** 与 **`html.theme-dark`**）。组件内 **只用 `var(--*)`**，禁止写死 `#16171d`、`#f3f4f6` 等。

常用对照：

| 语义 | 变量 |
|------|------|
| 页面底 | `--bg` |
| 次级块面 | `--code-bg`、`--social-bg` |
| 正文 / 标题 | `--text`、`--text-h` |
| 边线 | `--border` |
| 品牌交互强调 | `--accent`、`--accent-bg`、`--accent-border` |
| 强调色上的字 | `--on-accent` |
| 错误 | `--error-text`、`--error-bg`、`--error-border` |

## 字体与组件形态

- 正文 **`--sans`**，标题 **`--heading`**，数据与代码 **`--mono`**。
- 圆角约 **4px–8px**；卡片 **`border: 1px solid var(--border)`**，必要时底色用 **`--code-bg`**。
- 动效 **0.2s–0.3s**；**`focus-visible`** 使用 **`--accent`**。

## 应避免

- 把「黑色品牌」理解成 **整页纯黑 + 多处霓虹彩色**，破坏统一气质。
- 暗色下用 **重阴影** 造「浮起卡片」。
- 在组件 Less/TSX 中写死深色 hex，导致无法换肤或调对比度。

## 与工程的关系

- 默认 **`index.html`** 上 **`theme-dark`** 与 **`theme-color: #16171d`** 与黑色基调一致；若去掉 **`theme-dark`**，则回退为浅色 `:root`。
- 样式文件：**Less + BEM**；页面与组件约定见 **`app-structure.md`**。
