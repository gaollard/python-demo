# 论坛系统 PRD

> 基于 FastAPI Demo 实现一个轻量论坛后端：用户注册 → 登录 → 浏览/发布帖子 → 点赞/收藏。

---

## 1. 背景与目标

### 1.1 背景

当前 `fastapi-demo` 已具备 FastAPI + SQLAlchemy（aiomysql 异步）基础骨架，需要在此之上落地一套可演示、可扩展的论坛业务。

### 1.2 目标

- 完成论坛核心闭环：**注册 → 登录 → 看帖 → 发帖 → 点赞 → 收藏**
- 接口风格统一、鉴权清晰，便于后续扩展评论、关注等能力
- 与现有目录分层一致：`routers` / `schemas` / `models` / `services` / `core`

### 1.3 非目标（本期不做）

- 前端页面 / App
- 评论、回复、楼中楼
- 关注、私信、通知
- 内容审核、敏感词、举报
- 附件上传（非图片类型）
- 管理后台、角色权限（管理员）
- 搜索、推荐、热榜算法

---

## 2. 用户与场景

### 2.1 角色

| 角色 | 说明 |
|------|------|
| 游客 | 未登录用户，可浏览公开帖子列表与详情 |
| 登录用户 | 可发帖、点赞、收藏，可管理自己的帖子 |

### 2.2 核心用户旅程

```text
注册账号
   ↓
登录获取 Token
   ↓
浏览帖子列表 / 查看帖子详情
   ↓
（可选）点赞、收藏
   ↓
发布新帖
```

## 3. 功能需求

### 3.1 用户注册

| 项 | 说明 |
|----|------|
| 描述 | 新用户使用用户名 + 密码注册 |
| 前置条件 | 无 |
| 输入 | `username`（唯一）、`password` |
| 规则 | 用户名 3–32 位，字母数字下划线；密码 6–64 位；密码入库前哈希存储 |
| 成功 | 返回用户基本信息（不含密码） |
| 失败 | 用户名已存在 → `409`；参数不合法 → `422` |

### 3.2 用户登录

| 项 | 说明 |
|----|------|
| 描述 | 已注册用户登录，获取访问凭证 |
| 输入 | `username`、`password` |
| 成功 | 返回 `access_token`（JWT）及用户信息 |
| 失败 | 用户名或密码错误 → `401`（不区分具体原因） |
| 鉴权 | 后续写操作通过 `Authorization: Bearer <token>` 鉴权 |

### 3.3 查看帖子

#### 3.3.1 帖子列表

| 项 | 说明 |
|----|------|
| 权限 | 游客可访问 |
| 能力 | 分页浏览公开帖子，按创建时间倒序 |
| 查询参数 | `page`（默认 1）、`page_size`（默认 20，最大 50） |
| 返回字段 | `id`、`title`、`author`、`images`、`like_count`、`favorite_count`、`created_at` |

#### 3.3.2 帖子详情

| 项 | 说明 |
|----|------|
| 权限 | 游客可访问 |
| 返回字段 | 列表字段 + `content`（含 `images`）；若已登录，额外返回 `liked`、`favorited` |
| 失败 | 帖子不存在 → `404` |

### 3.4 发布帖子

| 项 | 说明 |
|----|------|
| 权限 | 需登录 |
| 输入 | `title`、`content`、可选 `images`（图片 URL 列表） |
| 规则 | 标题 1–100 字；正文 1–10000 字；图片最多 9 张，须先通过上传接口获得 URL |
| 成功 | 返回新建帖子完整信息，`201` |
| 失败 | 未登录 → `401`；参数不合法 → `422` |

### 3.4.1 帖子图片上传

| 项 | 说明 |
|----|------|
| 权限 | 需登录 |
| 描述 | 发帖前上传图片，返回可引用的 URL；创建帖子时把 URL 写入 `images` |
| 接口 | `POST /api/v1/uploads/images`（`multipart/form-data`，字段名 `files`） |
| 规则 | 仅 `jpeg`/`png`/`gif`/`webp`；单文件 ≤ 5MB；单次最多 9 张 |
| 成功 | 返回 `{ "urls": ["/media/uploads/....jpg", ...] }` |
| 失败 | 未登录 → `401`；类型/大小/数量不合法 → `400`/`422` |
| 访问 | 上传文件通过 `/media/...` 静态路径公开可读 |

### 3.5 点赞

| 项 | 说明 |
|----|------|
| 权限 | 需登录 |
| 能力 | 对帖子点赞 / 取消点赞（幂等） |
| 规则 | 同一用户对同一帖子只能点赞一次；重复点赞不报错，保持已点赞状态 |
| 接口建议 | `POST /posts/{id}/like` 点赞；`DELETE /posts/{id}/like` 取消 |
| 副作用 | 更新帖子 `like_count` |

### 3.6 收藏

| 项 | 说明 |
|----|------|
| 权限 | 需登录 |
| 能力 | 收藏 / 取消收藏（幂等） |
| 规则 | 同一用户对同一帖子只能收藏一次 |
| 接口建议 | `POST /posts/{id}/favorite` 收藏；`DELETE /posts/{id}/favorite` 取消 |
| 副作用 | 更新帖子 `favorite_count` |
| 扩展 | 支持「我的收藏」列表（可选本期实现） |

### 3.7 我的内容（建议本期包含）

| 能力 | 说明 |
|------|------|
| 我的帖子 | 当前用户发布的帖子列表（分页） |
| 我的收藏 | 当前用户收藏的帖子列表（分页） |

## 4. API 一览

| 方法 | 路径 | 鉴权 | 说明 |
|------|------|------|------|
| `POST` | `/api/v1/auth/register` | 否 | 注册 |
| `POST` | `/api/v1/auth/login` | 否 | 登录 |
| `GET` | `/api/v1/posts` | 否 | 帖子列表 |
| `GET` | `/api/v1/posts/{id}` | 可选 | 帖子详情 |
| `POST` | `/api/v1/posts` | 是 | 发布帖子 |
| `POST` | `/api/v1/uploads/images` | 是 | 上传帖子图片 |
| `POST` | `/api/v1/posts/{id}/like` | 是 | 点赞 |
| `DELETE` | `/api/v1/posts/{id}/like` | 是 | 取消点赞 |
| `POST` | `/api/v1/posts/{id}/favorite` | 是 | 收藏 |
| `DELETE` | `/api/v1/posts/{id}/favorite` | 是 | 取消收藏 |
| `GET` | `/api/v1/me/posts` | 是 | 我的帖子 |
| `GET` | `/api/v1/me/favorites` | 是 | 我的收藏 |

统一响应约定：

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

业务错误示例：`code != 0`，配合合适的 HTTP 状态码。

## 5. 数据模型（草案）

### 5.1 `user_tab` 用户

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `username` | VARCHAR(32) UNIQUE | 用户名 |
| `password_hash` | VARCHAR(255) | 密码哈希 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

> 现有 `User` 模型仅有 `id`/`name`，实现时需演进为上述结构（或迁移兼容）。

### 5.2 `post_tab` 帖子

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `user_id` | BIGINT | 作者 ID，索引 |
| `title` | VARCHAR(100) | 标题 |
| `content` | TEXT | 正文 |
| `images` | JSON | 图片 URL 列表，默认 `[]` |
| `like_count` | INT | 点赞数，默认 0 |
| `favorite_count` | INT | 收藏数，默认 0 |
| `created_at` | DATETIME | 创建时间 |
| `updated_at` | DATETIME | 更新时间 |

### 5.3 `post_like_tab` 点赞关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `user_id` | BIGINT | 用户 ID |
| `post_id` | BIGINT | 帖子 ID |
| `created_at` | DATETIME | 创建时间 |
| UNIQUE | `(user_id, post_id)` | 防重复点赞 |

### 5.4 `post_favorite_tab` 收藏关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | BIGINT PK | 主键 |
| `user_id` | BIGINT | 用户 ID |
| `post_id` | BIGINT | 帖子 ID |
| `created_at` | DATETIME | 创建时间 |
| UNIQUE | `(user_id, post_id)` | 防重复收藏 |

## 6. 非功能需求

| 类别 | 要求 |
|------|------|
| 技术栈 | FastAPI + Pydantic + SQLAlchemy Async + aiomysql + JWT |
| 安全 | 密码哈希（如 bcrypt/argon2）；JWT 过期时间可配置；敏感信息不入日志 |
| 性能 | 列表接口分页；点赞/收藏计数可用事务保证一致 |
| 可维护性 | 路由薄、业务进 `services`；Schema 与 ORM 分离 |
| 可观测 | 关键接口可在 `/docs` 调试；错误信息对客户端友好 |
| 配置 | 数据库与 JWT 密钥走 `.env`，参考现有 `docs/06-使用env文件.md` |

## 7. 验收标准

- [ ] 用户可注册、登录，未登录无法发帖/点赞/收藏
- [ ] 游客可浏览帖子列表与详情
- [ ] 登录用户可发布帖子，列表中可见
- [ ] 点赞、取消点赞幂等，计数正确
- [ ] 收藏、取消收藏幂等，计数正确
- [ ] 「我的帖子」「我的收藏」仅返回当前用户数据
- [ ] 非法参数返回 `422`，资源不存在返回 `404`，鉴权失败返回 `401`
- [ ] OpenAPI 文档（`/docs`）可完整演示上述流程
- [ ] 登录用户可上传图片并发帖，详情页可展示图片

## 9. 开放问题

1. 游客是否允许点赞/收藏？（当前结论：**否**，必须登录）
2. 是否支持删除/编辑自己的帖子？（建议 M3 后作为增强，默认本期可不做）
3. JWT 刷新机制是否需要？（本期可只发短期 `access_token`）
4. 点赞/收藏计数用冗余字段还是实时 `COUNT`？（建议冗余字段 + 事务，列表更轻）
5. 图片是否走对象存储？（本期本地磁盘 + `/media`；后续可换 S3/OSS）
