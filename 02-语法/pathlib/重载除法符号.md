对，平时 `/` 确实是除法。这里能这么写，是因为 `Path` **重载了** `/` 运算符。

对 `Path` 对象来说：

```python
Path("/tmp/project") / "data" / "out.txt"
```

等价于：

```python
Path("/tmp/project").joinpath("data", "out.txt")
# → PosixPath('/tmp/project/data/out.txt')
```

设计意图是：路径本来就用 `/` 分隔（Unix 风格），所以用 `/` 拼接比 `os.path.join(...)` 更直观。

注意：
- 左边必须是 `Path`（或链式结果仍是 `Path`）
- `"a" / "b"` 会报错，因为普通字符串没有这个重载
- 真正做除法时，两边是数字，和 `Path` 无关
