## 在子类中如何调用父类的方法

子类重写父类方法后，仍可用 `super()` 或「父类名.方法」调用父类实现，常见于扩展而非完全替换。

### 方式一：`super()`（推荐）

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        print(f"{self.name} makes a sound")


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)   # 调用父类 __init__
        self.breed = breed

    def speak(self):
        super().speak()          # 先执行父类逻辑
        print(f"{self.name} says woof!")


dog = Dog("Buddy", "Husky")
dog.speak()
# Buddy makes a sound
# Buddy says woof!
```

优点：写法简洁，多继承时会按 MRO（方法解析顺序）正确找下一个父类。

### 方式二：父类名.方法名(self, ...)

```python
class Dog(Animal):
    def speak(self):
        Animal.speak(self)       # 显式指定父类，并传入 self
        print(f"{self.name} says woof!")
```

能用，但写死了类名，多继承或改父类时不如 `super()` 灵活。

### 小结

| 写法 | 说明 |
|---|---|
| `super().方法()` | 推荐，配合 MRO，适合单/多继承 |
| `父类.方法(self, ...)` | 可用，但类名写死，维护成本更高 |

最常见场景：子类 `__init__` 里 `super().__init__(...)`，先完成父类初始化，再加子类自己的属性。
