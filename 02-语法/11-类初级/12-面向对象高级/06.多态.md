# 多态

同一套调用方式，不同对象表现出不同行为。调用方只关心「会不会这个方法」，不关心具体是哪个类。

封装管「藏细节」，继承管「复用与扩展」，多态管「同一接口、多种实现」。

## 继承里的多态

子类重写父类方法后，用父类类型（或统一变量）去调，实际跑的是子类自己的实现：

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        raise NotImplementedError("子类必须实现 speak")


class Dog(Animal):
    def speak(self):
        return f"{self.name} says woof!"


class Cat(Animal):
    def speak(self):
        return f"{self.name} says meow!"


def make_sound(animal: Animal):
    print(animal.speak())   # 不关心是 Dog 还是 Cat


make_sound(Dog("Buddy"))  # Buddy says woof!
make_sound(Cat("Mimi"))   # Mimi says meow!
```

`make_sound` 只依赖「有 `speak`」，换不同子类，行为自动变。这就是多态带来的扩展性：加新动物一般不用改调用方。

和同目录 `code/04.py` 一样：`Dog` / `Cat` 都继承 `Animal`，各自实现 `speak`。

## 鸭子类型（Python 更常见）

Python 是动态类型：**不看你是不是某个父类的子类，只看你有没有需要的方法和属性**。

> 走起来像鸭子、叫起来像鸭子，那它就可以当鸭子用。

```python
class Dog:
    def speak(self):
        return "woof"


class Car:
    def speak(self):   # 和 Animal 无关，只是碰巧也有 speak
        return "vroom"


def make_sound(obj):
    print(obj.speak())


make_sound(Dog())  # woof
make_sound(Car())  # vroom —— 没有继承 Animal，也能用
```

优点：灵活，少写强制继承。  
代价：没有统一父类时，缺方法要等到运行时才报错（`AttributeError`）。

日常 Python 代码里，**鸭子类型往往比「必须继承同一基类」更常见**（例如任何实现了 `__iter__` 的对象都能 `for` 遍历）。

## 用抽象基类把「接口」说清楚

想强制「子类必须实现某些方法」，可以用 `abc`（Abstract Base Class）：

```python
from abc import ABC, abstractmethod


class Animal(ABC):
    @abstractmethod
    def speak(self):
        """子类必须实现"""


class Dog(Animal):
    def speak(self):
        return "woof"


# Animal()          # TypeError：不能实例化抽象类
# class Bird(Animal): pass
# Bird()            # TypeError：没实现 speak

print(Dog().speak())  # woof
```

适合：团队约定接口、框架插件点、希望「忘写方法立刻报错」而不是跑到半路才炸。

## 运算符重载也是多态

同一个运算符，作用在不同类型上行为不同——也是多态的一种：

```python
print(1 + 2)        # 3，整数加法
print("a" + "b")    # ab，字符串拼接

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"


print(Vector(1, 2) + Vector(3, 4))  # Vector(4, 6)
```

`+` 对 `int`、`str`、自定义类各有实现，调用形式相同。

## 和继承、重写的关系

| 概念 | 作用 |
|---|---|
| 继承 | 拿到父类接口 / 行为 |
| 重写（override） | 子类换成自己的实现 |
| 多态 | 用统一方式调用，运行时落到具体对象的实现 |

没有「同一接口下的多种实现」，光有继承也不叫多态；没有运行时按对象选方法，重写也发挥不出多态的价值。

## 小结

| 形式 | 要点 |
|---|---|
| 继承多态 | 子类重写父类方法，调用方按统一接口使用 |
| 鸭子类型 | 有同名方法就能用，不强制继承（Python 主流） |
| 抽象基类 | `@abstractmethod` 强制子类实现接口 |
| 运算符重载 | 同一运算符，不同类型不同实现 |

写代码时：对外暴露稳定接口（方法名、参数约定）；对内用不同类填不同实现。Python 里优先靠鸭子类型保持简单，接口必须硬约束时再上 `abc`。
